2. The matrix

Cases are generated from the enums and the table (app/test/support/output_matrix.dart): every container × audio mode (Passthrough where the container copies the source's codec; Convert × each codec the container takes; Restore; Restore + Convert AAC) × source class × trim (none, 2..51, 40..89), plus ProRes Proxy/MOV and AV1/MP4 rows for Passthrough and Restore. The sources (generate_output_conformance.sh) share one content: 160x120 testsrc2 at 25 fps, 100 pictures, white at 5, 30, 55, 80, each with a 20 ms click on a quiet tone.

Each case checks: (1) the header writes with the expected audio codec; (2) picture count and first picture time (AVI: stored frames and rate); (3) no empty video packets, pictures one frame apart; (4) each white frame's click within one audio packet; (5) audio packets follow on, plus task #41's AAC block size in AVI; (6) lossless paths: a copy is a run of the source's payload bytes, FLAC/PCM are the source's samples to the output's depth.

Corrections to the oracle (review, 2026-11-16)

The first full run failed 109 cases; most were the oracle's, not the product's, and are left here so the numbers can be traced:

  • The sample check aligned on the first match. The tone between clicks repeats, so a trimmed output's first 4,800 samples matched the source a whole number of periods early, and every click then “differed”. It now compares each matching offset in full and keeps the best (on mp4/convert-flac/plain/mid: offset 30720 with 16,458 differing samples → 76800 with none).
  • AVI gives its first audio chunk no duration (and FLAC chunks none at all), which the packet check read as 0: 27 AVI cases reported packet 1 one packet late. A missing duration is now the stream's usual one; with none, only order is checked.
  • ffprobe names MP2 in MP4 mp3 or mp2, depending on how much it parses (MP4 shares one object type for both layers). Either is accepted for MP4.
